Don't be a silly goose

Sometimes, someone enters a chat room and asks:

Foobar123:

Any Java experts around?

Asking the full question would probably be more useful.

Still, replying with only this:

SomeoneElse:

https://dontasktoask.com

can come across as colder than intended.

A simple reply usually works just as well:

HelpfulPerson:

Java Dev here, you can just post the question directly next time!

Same advice, friendlier delivery.

Ask complete questions when you can. When someone does not, a small nudge is usually enough.

A gentle response to dontasktoask.com.
